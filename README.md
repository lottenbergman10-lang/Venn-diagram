# Venn-diagram

En Mac-app för att skapa Venn-diagram från användarens listor, med automatiska överlappszoner och inställningar för färg och genomskinlighet.

Appen byggs med Swift och SwiftUI. Den första prototypen visar ett förskapat diagram när användaren klickar på **Visa exempeldiagram**. Sju exempelpersoner är placerade i zonerna för intressena Skriver, Fotograferar och Formger.

## Kör appen

1. Öppna `VennDiagram.xcodeproj` i Xcode.
2. Välj schemat **VennDiagram** och destinationen **My Mac**.
3. Klicka på körknappen eller tryck på **⌘R**.
4. Klicka på **Visa exempeldiagram** i appen. Returtangenten fungerar också.

Prototypen kräver macOS 14 eller senare. Inmatning av egna listor samt reglage för färg och genomskinlighet återstår att utveckla.

Projektet använder lokal ad hoc-signering för provkörning på den egna datorn.
